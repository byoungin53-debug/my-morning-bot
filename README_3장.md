# 유튜브 요약 한 통 (3장)

내가 보는 유튜브 채널에 새 영상이 올라오면, 영상마다 **제목 / 요약 3줄 / 영상 링크**를 묶어 아침에 텔레그램 한 통으로 보내 줍니다.
2장에서 만든 것(API 열쇠·텔레그램 봇·깃허브 저장소·비밀값 3개)을 그대로 씁니다. 새로 만들 열쇠는 없습니다.

받는 모양(예시):
```
○/○(○) 유튜브 요약 2편

제목: [돈보라] "600만원 넣었더니 99만원 돌려주네요?" …
(요약 첫째 줄)
(요약 둘째 줄)
(요약 셋째 줄)
영상링크 : https://youtu.be/W8DkFJpDYKk

제목: [시황맨TV] 주식 시황. 코스피 …
영상링크 : https://youtu.be/72DKbCzCFOw
```
요약 3줄이 없는 영상 = 자막을 못 가져온 영상입니다(아래 "꼭 먼저 읽기").

---

## 꼭 먼저 읽기 — 어디서 돌리느냐에 따라 결과가 다릅니다

| | 노트북에서 돌리기 | 깃허브에서 돌리기 |
|---|---|---|
| 노트북이 꺼져 있으면 | 안 옴(켜면 그때 옴) | 옴 |
| 요약 3줄 | **옴** (자막을 가져올 수 있음) | **안 올 때가 많음** — 유튜브가 클라우드 컴퓨터의 자막 요청을 자주 막습니다. 막히면 제목·링크만 옵니다 |
| 돈 | 요약할 때마다 AI 요금이 나감 | 자막이 막힌 날은 AI를 안 불러 0원 |

그래서 **먼저 깃허브에서 "점검" 버튼(돈 0원)으로 내 저장소에서 자막이 되는지 봅니다.** 되면 깃허브로, 안 되면 노트북으로 씁니다.
**둘 중 하나만 켜세요.** 둘 다 켜면 같은 영상이 두 번 옵니다.

**주의:** 인터넷에 "유튜브 쿠키를 넣으면 깃허브에서도 된다"는 방법이 있습니다. **쓰지 마세요.** 내 구글 계정 로그인 정보를 넣는 것이라 계정 정지·유출 위험이 있습니다.

---

## 1. 보고 싶은 채널 적기 — `channels.txt` 한 곳만 고칩니다

1. 유튜브에서 채널 이름을 눌러 채널 첫 화면으로 갑니다.
2. 주소창의 주소를 복사합니다. 예: `https://www.youtube.com/@moneybora`
3. `channels.txt` 에 한 줄에 하나씩 붙여넣습니다. 맨 앞에 `#` 이 붙은 줄은 무시됩니다.

```
https://www.youtube.com/@moneybora
https://www.youtube.com/@sugkamoney
```

채널 ID(UC로 시작하는 24글자)를 적어도 됩니다. 주소가 맞는지 확인하려면 VS Code 터미널에서(돈 0원):
```
python yt_bot.py --find-id https://www.youtube.com/@moneybora
```
→ `https://www.youtube.com/@moneybora  →  UChlGdImhOBo3SwFFF9mRCcQ  (돈보라)` 처럼 채널 이름이 나오면 맞는 주소입니다.

깃허브 화면에서 고칠 때: 저장소 → `channels.txt` 클릭 → 연필 아이콘 → 고치기 → **Commit changes**.

---

## 2. 깃허브에서 쓰기 (노트북 꺼져도 옴)

### 2-1. 자막이 되는지 점검 (돈 0원)
내 저장소 → **Actions** 탭 → 왼쪽 **유튜브 요약 한 통** → **Run workflow** → mode 에서 **check** 그대로 → 초록 **Run workflow**

실행 기록이 초록 체크가 되면 → `send` → **점검만** 단계를 열어 맨 아래를 봅니다.
- `결과: 영상 N편 중 자막 성공 N편`(성공이 1편 이상) → 깃허브로 써도 요약이 옵니다.
- `실패: RequestBlocked` / `실패: IpBlocked` 가 줄줄이 → 유튜브가 막는 중입니다. 요약을 받으려면 **3. 노트북에서 쓰기**로 가세요.

### 2-2. 진짜 한 통 보내기 (돈 나감)
같은 화면에서 mode 를 **send** 로 바꾸고 Run workflow. 폰에 한 통이 오면 성공입니다.
**한 번만 누르세요.** 자막을 가져온 영상이 있으면 누를 때마다 AI를 1번 부릅니다.

### 2-3. 끝
매일 아침 7시 47분(한국 시간)에 돌도록 예약돼 있습니다. 깃허브가 바쁘면 늦을 수 있습니다.
새 영상이 없는 날은 아무것도 오지 않습니다(돈 0원).

## 3. 노트북에서 쓰기 (요약이 확실히 옴, 노트북이 켜져 있어야 함)

### 3-1. 파일 받기
내 깃허브 저장소 → 초록 **Code** 버튼 → **Download ZIP** → 압축 풀기 → VS Code 로 그 폴더 열기.

### 3-2. 도구 설치 (한 번만)
VS Code 터미널에:
```
pip install -r requirements_yt.txt
```

### 3-3. 비밀값 파일 만들기
같은 폴더에 새 파일 `secrets.local.json` 을 만들고 아래처럼 적습니다(따옴표 안에 내 값).
```
{
  "ANTHROPIC_API_KEY": "여기에 API 열쇠",
  "BOT_TOKEN": "여기에 봇 토큰",
  "CHAT_ID": "여기에 채팅 번호"
}
```
- API 열쇠를 적어 둔 곳이 없으면 Console 왼쪽 **API 키** → **키 생성**으로 새로 만듭니다(영어 화면이면 **API keys**).
- 이 파일은 **절대 깃허브·카톡·채팅에 올리지 않습니다.** (`.gitignore` 에 `secrets*.json` 이 있어 깃허브에는 자동으로 안 올라갑니다)
- 넷리파이 사이트 폴더에도 넣지 마세요.

### 3-4. 점검 (돈 0원)
```
python yt_bot.py --check
```
`자막 … 성공 ○○○○자` 처럼 나오면 됩니다.

### 3-5. 진짜 한 통 (돈 나감, 한 번만)
```
python yt_bot.py
```
폰에 한 통이 오면 성공입니다.

### 3-6. 매일 아침 자동으로 (작업 스케줄러)
VS Code 터미널(PowerShell)에서 이 폴더에 있는 상태로 붙여넣습니다. 노트북이 그 시각에 꺼져 있었으면 **켠 뒤 바로** 돌게 해 둡니다.
```
$a = New-ScheduledTaskAction -Execute "$PWD\run_laptop.cmd"
$t = New-ScheduledTaskTrigger -Daily -At 7:47am
$s = New-ScheduledTaskSettingsSet -StartWhenAvailable -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
Register-ScheduledTask -TaskName "유튜브요약" -Action $a -Trigger $t -Settings $s
```
기록은 같은 폴더 `yt_bot.log` 에 쌓입니다.

**노트북으로 쓰기로 했으면 깃허브 쪽은 꺼 두세요**(아래 "끄는 법").

## 돈은 얼마나 드나요?

- 모델은 `claude-haiku-5-5` 입니다.
- 실제 금액은 첫 실행 뒤 Console 왼쪽 **분석 → 비용** 화면에서 확인합니다(영어 화면이면 **Usage**). 실행 기록의 "AI 사용량" 줄에도 쓴 토큰 수가 나옵니다.
- 한 번에 영상 최대 10편, 자막 최대 40,000자까지만 AI에게 보내도록 막아 두었습니다. 이 숫자를 키우면 요금이 오릅니다.
- 새 영상이 없거나 자막을 하나도 못 가져온 날은 AI를 부르지 않습니다(0원).
- 2장에서 건 월 한도(Console **관리 → 결제 → 지출 한도**, 영어 화면 **Billing → Spend limits**)가 그대로 지켜 줍니다.

## 안 올 때

깃허브: Actions → 맨 위 실행 기록 → 빨간 X 단계 → 맨 아래 글. 노트북: `yt_bot.log` 맨 아래.

| 화면에 나온 글 | 뜻 | 할 일 |
|---|---|---|
| 새 영상 0편 | 최근 30시간 새 영상이 없음 | 정상(돈 0원) |
| channels.txt 에 채널이 한 줄도 없습니다 | 채널을 안 적었거나 `#` 을 안 지움 | 1번 다시 |
| 그런 채널 주소가 없습니다 | 주소 오타 | `--find-id` 로 확인 |
| 실패: RequestBlocked / IpBlocked | 유튜브가 이 컴퓨터의 자막 요청을 막음. 노트북도 짧은 시간에 여러 번 돌리면 막힙니다 | 깃허브면 노트북으로. 노트북이면 몇 시간 뒤 한 번만 다시. 점검·실행을 연달아 누르지 않기 |
| 실패: NoTranscriptFound / TranscriptsDisabled | 그 영상에 자막이 없음 | 그 영상은 제목·링크만 옵니다 |
| 멈춤: 비밀값 ○○ 이(가) 없습니다 | Secrets 또는 secrets.local.json 이름이 틀림 | 이름을 글자 그대로 |
| 멈춤: 요약 3줄이 맞지 않는 영상 | AI가 양식을 안 지킴 | 발송 안 함(잘못된 글을 안 보냄). 다음 날 다시 돕니다 |
| 멈춤: AI 글이 끝까지 안 써졌습니다 | 글이 잘림 | 발송 안 함 |
| 멈춤: 텔레그램 발송 실패 403 | 봇에게 먼저 말을 안 걸었음 | 내 봇에게 아무 말이나 보내기 |

**실패했다고 여러 번 누르지 마세요.** 원인부터 보고 한 번만 다시 누릅니다.

## 꼭 알아 둘 것

- 이미 보낸 영상은 `yt_sent.json` 에 적어 두고 다시 보내지 않습니다. 깃허브에서는 보낸 날마다 이 파일이 저장소에 자동 저장됩니다.
- 저장소가 공개(Public)면 `channels.txt`(내가 보는 채널 목록)도 누구나 볼 수 있습니다. 싫으면 비공개(Private)로 만드세요. 비공개 저장소는 실행 시간이 깃허브 무료 사용 시간에서 빠지니 깃허브 내 계정 설정의 Billing 화면에서 사용량을 가끔 확인하세요.
- 공개 저장소는 60일 동안 아무 변화가 없으면 깃허브가 예약 실행을 저절로 끕니다. 두 달에 한 번 Actions 탭에서 켜져 있는지 보세요.
- 끄는 법: 깃허브 = Actions → 유튜브 요약 한 통 → 오른쪽 위 `…` → **Disable workflow** / 노트북 = PowerShell 에 `Unregister-ScheduledTask -TaskName "유튜브요약" -Confirm:$false`.
