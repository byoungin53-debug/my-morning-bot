# 아침 뉴스 한 통

매일 아침, 경제·재테크 뉴스를 모아서 AI가 짧게 정리한 글 **한 통**을 내 텔레그램으로 보내 줍니다.
내 노트북이 꺼져 있어도 깃허브가 대신 돌려 줍니다.

---

## 어떻게 움직이나요?

1. **뉴스 모으기** — 신문사·구글 뉴스가 공짜로 내주는 뉴스 목록(RSS)에서 최근 하루 기사 제목을 최대 40개 가져옵니다. (돈 안 듦)
2. **AI 요약 1번** — 모은 제목을 클로드에게 한 번 보내 "아침 뉴스 한 통"으로 정리하게 합니다. (**여기서만 돈이 나갑니다**)
3. **텔레그램 보내기** — 정리된 글을 내 텔레그램으로 보냅니다. (돈 안 듦)

---

## 준비물 3가지 (비밀값)

| 이름 | 무엇인가요 | 어디서 받나요 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 클로드 API 열쇠 | Claude Console(platform.claude.com) |
| `BOT_TOKEN` | 내 텔레그램 봇의 열쇠 | 텔레그램 @BotFather |
| `CHAT_ID` | 내 텔레그램 채팅 번호 | 봇에게 말 건 뒤 확인 |

**이 3개는 절대 코드나 채팅·카톡에 붙여넣지 마세요.** 깃허브 Secrets(비밀 금고)에만 넣습니다.
하나라도 빠지면 프로그램은 아무것도 하지 않고 멈춥니다.

---

## 따라 하기

### 1. 이 저장소를 내 것으로 복사
먼저 깃허브에 **로그인**합니다. 로그인해야 이 페이지 위쪽에 초록색 **Use this template** 버튼이 보입니다(로그아웃 상태에서는 버튼이 안 보입니다).
그 버튼으로 내 계정에 새 저장소를 만듭니다. 공개(Public)로 만들면 깃허브 Actions 시간이 무료입니다.

### 2. 비밀값 3개 넣기
내 저장소 → **Settings** → 왼쪽 **Secrets and variables** → **Actions** → **Secrets** 탭 → **New repository secret**
- Name 칸에 `ANTHROPIC_API_KEY`, Secret 칸에 열쇠 → **Add secret**
- 같은 방법으로 `BOT_TOKEN`, `CHAT_ID`

이름은 위와 **글자 하나 다르지 않게** 적어야 합니다.

### 3. 한 번 직접 돌려 보기
내 저장소 → **Actions** 탭 → 왼쪽 **아침 뉴스 한 통** → **Run workflow** 버튼
잠시 뒤 폰 텔레그램에 뉴스 한 통이 오면 성공입니다.
**버튼을 누를 때마다 AI를 1번 부르므로 돈이 조금 나갑니다.** 한 번만 눌러 보세요.

### 4. 끝
이제 매일 아침 7시 17분(한국 시간)에 자동으로 돌도록 예약되어 있습니다. 깃허브가 바쁘면 늦게 올 수 있습니다.

---

## 돈은 얼마나 드나요?

- 모델: `claude-haiku-5-5` (입력 100만 토큰당 $0.10, 출력 100만 토큰당 $0.50)
- AI는 하루 1번만 부릅니다. 기사는 최대 40개, AI 글 길이에도 상한이 있습니다.
- **실제 금액은 첫 실행 뒤 Console의 Usage 화면에서 확인합니다.**
- 웹검색 기능은 쓰지 않습니다(쓰면 요금이 따로 붙습니다).

**켜기 전에 꼭: 월 한도 걸기**
Console → **Settings → Billing** → **Spend limits** → **Set limit**(또는 Adjust limit) → 예: $5
한도에 닿으면 그달은 AI가 멈추고, 뉴스도 오지 않습니다. 돈이 계속 나가는 일은 없습니다.

## 바꿔 보고 싶을 때

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 받고 싶은 뉴스 주제 | `news_bot.py` 의 `FEEDS` — 구글 뉴스 검색어(`_google("검색어")`)만 바꾸면 됩니다 |
| 글 모양·길이 | `prompt.txt` (주문서) |
| 보내는 시각 | `.github/workflows/news.yml` 의 `cron` 줄 — 깃허브 시계는 한국보다 9시간 느립니다. 정각(00분)·30분은 피하세요 |
| 더 똑똑한 모델 | `news_bot.py` 의 `MODEL` 을 `claude-sonnet-5-5` 로 (입력 $2 / 출력 $10, 값이 올라갑니다 — 바꾼 뒤 Usage 화면에서 확인) |

고친 뒤에는 꼭 한 번 **Run workflow** 로 폰에 오는지 확인하세요. "코드가 돌았다"가 아니라 **폰에 왔다**가 성공입니다.

## 안 올 때

Actions 탭 → 맨 위 실행 기록 클릭 → 빨간 X 단계 열기 → 맨 아래 "멈춤:" 글을 읽습니다.

| 화면에 나온 글 | 뜻 | 할 일 |
|---|---|---|
| 멈춤: 비밀값 ○○ 이(가) 없습니다 | Secrets 이름이 틀렸거나 빠짐 | 2번 다시 |
| 멈춤: 기사가 0건 | 뉴스 사이트가 잠깐 막힘 | 다음 날 자동으로 다시 돕니다(돈 0원) |
| 멈춤: AI 글이 끝까지 안 써졌습니다 | 글이 너무 길어 잘림 | 발송 안 함. `prompt.txt` 길이 줄이기 |
| 멈춤: 텔레그램 발송 실패 | 봇에게 먼저 말을 안 걸었거나 CHAT_ID가 틀림 | 텔레그램에서 내 봇에게 아무 말이나 보내고, CHAT_ID 다시 확인 |
| 401 / authentication | API 열쇠가 틀림 | 새 열쇠를 만들어 Secrets 다시 넣기 |
| usage limits | 월 한도에 닿음 | Billing 에서 한도 확인 |

**실패했다고 Run workflow 를 여러 번 누르지 마세요.** 원인부터 보고 한 번만 다시 누릅니다.

## 꼭 알아 둘 것

- **공개 저장소는 60일 동안 아무 변화가 없으면 깃허브가 예약 실행을 저절로 끕니다.** 두 달에 한 번은 Actions 탭에서 다시 켜져 있는지 보거나, 파일을 한 줄 고쳐 저장하세요.
- 공개 저장소의 실행 기록(로그)은 누구나 볼 수 있습니다. 비밀값은 깃허브가 `***`로 가려 주지만, 비밀값을 `print` 하는 코드를 넣지 마세요.
- 끄고 싶으면: Actions 탭 → 아침 뉴스 한 통 → 오른쪽 위 `…` → **Disable workflow**.
